How to read this map

The original request is preserved in project-brief.md. This page records implemented behavior and verification targets, not a guarantee about an untested deployment. Run yarn verify for the automated suite and build; use the release checklist for physical Windows, printer and network checks.

Scope interpretations

Inventory is deducted when an order completes. Clients may edit orders through one master. Per-machine installation uses per-user runtime data. Local administrator unlock controls access to Audit. “POS” describes order recording here; external payments are not integrated.

Manual release checklist

  1. Build the NSIS installer. Install for all users with administrator elevation and confirm both shortcuts launch correctly.
  2. Launch under a standard Windows account. Confirm its own data path, first-run demo, password setup and subsequent restart persistence.
  3. Exercise the full workflow on a touchscreen: search, variant choice, quantity, fees, notes, order, edit, completion and receipt.
  4. Print a receipt on the actual target printer and paper width. Confirm amounts, accents/symbols and page layout.
  5. Configure a master and kitchen on two physical devices. Verify registration, propagation, order completion, conflict handling and reconnect behavior.
  6. Make a backup, restore a closed-app folder copy to a test location and confirm the recovered state. Exercise malformed menu JSON in a disposable dataset.
  7. Before a live trading day, use Start fresh, enter opening stock and check tax/fee settings with the business owner. Keep a separate backup of the prepared store.
